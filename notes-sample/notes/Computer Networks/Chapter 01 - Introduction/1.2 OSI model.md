# OSI model

The OSI model splits communication into **seven layers**.

| # | Layer | Job |
|---|-------|-----|
| 7 | Application | Network services for apps |
| 6 | Presentation | Encoding, encryption |
| 5 | Session | Opens and closes sessions |
| 4 | Transport | End-to-end delivery |
| 3 | Network | Routing |
| 2 | Data Link | Frames, MAC addresses |
| 1 | Physical | Bits on the wire |
