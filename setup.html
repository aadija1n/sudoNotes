Admin setup

Create the login for writing mode. Everything happens in this browser tab. Nothing you type is sent anywhere except a read-only check against GitHub.

1. Your details

How to create the GitHub token
  1. GitHub → your profile → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, then pick BOTH the notes repository and the site repository (the one that holds index.html and auth.json).
  3. Permissions → Repository permissions → Contents: Read and write. The site repository permission is only needed for the one-time “Set notes repository” save; everyday note edits only touch the notes repository.
  4. Choose an expiration (for example 1 year) and generate. Copy the token. It starts with github_pat_.
  5. Already have a token and auth.json? Editing a token's repositories or permissions does not change the token string, so your existing auth.json stays valid. You only need to run this page again for a new token or password.

2. Add the file to your site repository

  1. In your repo on GitHub choose Add file → Upload files and drop auth.json next to index.html in the site repository (not the notes repository). (Or choose Create new file, name it auth.json and paste the text.)
  2. Commit it, wait a minute for GitHub Pages to publish, then open your site and click W.
  3. Forgot the password or the token expired? Run this page again and replace auth.json.

The repo is public, so anyone can read auth.json. Your token inside it is encrypted with your password, so a longer password means better protection.
